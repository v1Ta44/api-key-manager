## 最终界面与功能

- 暖灰纸白、绿色主操作，以及对应深色主题；所有生产颜色来自统一的深浅资源字典。
- 名称/平台、密钥摘要、到期状态与行内复制构成列表；完整连接信息、日期、备注、编辑和删除进入详情栏。
- 900 像素宽时切换为列表/详情单栏，编辑与数据管理使用可滚动侧面板，确认和取消固定在底部。
- 搜索原来的六类文本，增加平台、标签、到期筛选。新增或修改后如被筛选隐藏，会返回全部记录并选中保存项。
- 真实复制完整密钥或 URL，按钮旁即时反馈；只允许显示单条密钥，10 秒后自动遮挡。重新解锁不恢复旧的全局明文偏好。
- 初次建库、解锁、增删改、独立密码的加密备份、导入预览/合并/替换、导入偏好、CSV 确认、改主密码均接入生产应用层。
- 自动锁定和剪贴板清理有明确的启用开关；闲置到期前 30 秒提示未保存草稿将清除。

## 前后端边界

`Core` 继续负责既有数据格式和纯规则。新增无 WPF 依赖的 `Application`，拥有解密会话、当前密码、串行写入和导入候选。

`WorkspaceViewModel` 负责页面状态和调用应用功能，不保存主密码属性。列表和详情收到的是不含明文密钥的摘要；编辑需要时取得独立草稿。`WorkspaceWindow` 只处理控件、焦点、尺寸、Windows 文件选择与服务生命周期。

旧主窗口、旧 MainViewModel、四组旧弹窗及其主题/转换器已经移除，当前工作树的默认入口使用新窗口。历史 A/B 原型仍有隔离的 `--prototype` 入口，共用正式控件样式，不作为第二套生产业务实现。旧 UI 可以从基础提交取回；没有制造新的 Git 提交。

## 已修复的可靠性问题

| 原问题 | 新行为及证据 |
| --- | --- |
| 先改内存，保存失败后界面和文件不一致 | 候选文件成功写入、回读校验并替换后，才发布新状态；增删改失败注入测试通过 |
| 改密码失败后会话误用新密码 | 写入验证成功才切换凭据；失败后继续用旧密码保存的测试通过 |
| 覆盖前备份失败仍继续 | 备份失败停止替换，原记录保留；可恢复副本在隔离文件流程中实际生成 |
| 锁定时编辑/后台任务恢复旧数据 | 会话版本失效，清空草稿、摘要和明文；已开始的写入可以收尾，但不重新展示数据 |
| 剪贴板清理没有定时驱动、强制清理误删后来复制的内容 | 独立计时器驱动；包括锁定时也先匹配自己的内容；被占用最多尝试五次，失败可见 |
| 主题启动/导入偏好不生效 | 启动应用已保存主题；导入可恢复有效偏好；设置失败保留原值并提示 |
| 多实例竞争写入 | 同一库路径持有独占文件句柄；同路径排他、不同路径可用和释放后重开测试通过 |
| 演示数据未自动解锁、可覆盖指定目录 | 隔离演示自动解锁；指定目录有库或设置时拒绝覆盖 |
| 发布验证停止所有同名进程、删除输出 | 每次创建新产物目录，仅运行本次检查；不停止用户进程、不删除旧产物 |
