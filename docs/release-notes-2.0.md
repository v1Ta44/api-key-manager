# API Key 管理器 2.0.0

采用「温润档案风」界面与一体式窗口顶栏，支持深浅主题、搜索筛选、单条密钥短时显示、加密备份和导入。保存会先验证候选文件，保存失败保留原库和编辑内容；同一个库只允许一个新版窗口写入。

## 运行

推荐使用 `sc` 自包含包：解压整个目录后运行 `ApiKeyManager.exe`，不需要另装 .NET。请勿只复制 exe，另外的原生组件也必须保留。

`fd` 框架依赖包需要 x64 .NET 9 Desktop Runtime **9.0.20 或更新的 9.0 补丁版**。Windows 10/11 x64；本次自动验证系统为 Windows 11，Windows 10 独立机器尚未验证。布局最低需要 900×600 个逻辑像素；例如 200% 缩放需至少 1800×1200 的可用物理像素，不含任务栏。

本版未作开发者代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。可使用发行附件中的 SHA256SUMS.txt 核对下载文件。

## 发布验证

本版通过 155 项自动测试、两种产物各 79 项窗口检查，以及 58 条打包、归档完整性和隔离启动检查。自包含包还通过了共享运行时路径不可用时的窗口检查。

维护者明确决定跳过剩余人工检查并发布。此前核心操作、自动保护和顶栏基本操作已有用户确认；下面列出的系统缩放、多屏、完整键盘/读屏和干净机器等项目仍是未验证，不代表测试通过。

## 首次使用与旧版升级

1. 首次运行设置至少 8 位主密码。主密码无法找回。
2. 升级前关闭旧版，从旧版导出加密备份，并另行保存现有 `vault.akv` 和 `settings.json`。不要让新旧版同时打开同一个库。
3. 把新版解压到新目录，先用备份副本验证解锁与记录数量。也可以用 `ApiKeyManager.exe --dir "数据目录"` 明确指定经过备份的目录。
4. 默认优先在程序目录保存；不可写时使用 `%APPDATA%\ApiKeyManager`。界面「数据与设置」显示当前数据路径。移动程序目录不会自动迁移其他目录的库。
5. 密码派生强度较旧时，新版先创建 `vault.akv.<时间>.bak` 再升级；替换导入前也会创建恢复副本。回退需要关闭程序并恢复经过验证的完整备份，新产生的修改不会自动合并到旧备份。

保留 v1 库/备份格式与所有记录字段。CSV 包含明文密钥，只适合明确需要明文文件时使用。备份副本仍受其创建时的旧密码保护，修改当前主密码不会改写以前的备份。

## 保护与操作

默认闲置 5 分钟锁定、复制后 30 秒清理；只有剪贴板内容仍与本次复制相同才清理。闲置锁定会清除未保存草稿。剪贴板被其他进程持续占用时，重试失败会显示提示；关闭程序后不能继续重试。

快捷键：Ctrl+F 查找、Ctrl+N 新增、Ctrl+L 锁定、Ctrl+T 主题、Escape 取消面板、Alt+Space 系统菜单。窗口顶部空白区域可拖动和双击最大化/还原。
